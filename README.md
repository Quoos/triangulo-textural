# Triângulo Textural do Solo

**Aplicação web para determinação da classe textural do solo**, a partir dos percentuais de **argila**, **silte** e **areia**.

---

## ℹ️ Sobre a ferramenta

A textura do solo é de fundamental importância para a compreensão do comportamento e manejo do solo. Durante a classificação do solo em um determinado local, a textura é muitas vezes a primeira e mais importante propriedade a ser determinada. A partir da mesma, muitas conclusões importantes podem ser tomadas.

Nesta ferramenta, os solos podem ser agrupados em 13 classes texturais. Basta inserir os valores de Argila, Silte e Areia (em %) e clicar em "Enviar". A classe textural correspondente será exibida graficamente.

## 🚀 Como usar

1. Hospede os arquivos `index.html` e `triangulotextural.js` em qualquer servidor web (GitHub Pages, Netlify, etc.)
2. Abra o `index.html` no navegador.
3. Insira os valores de **argila**, **silte** e **areia** de uma amostra, totalizando 100%.
4. Visualize a classe textural correspondente conforme o triângulo.

---

## 🧪 Exemplo de uso

- Argila: 25%
- Silte: 30%
- Areia: 45%

Resultado: Classe **Franco Argilo Arenosa**
